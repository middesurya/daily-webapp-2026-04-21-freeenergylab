The Markov Blanket

$$p(\mu | \eta, s, a) = p(\mu | s, a)$$

Internal states μ are shielded from external states η by the blanket B = {s, a}. Sensory states carry information inward; active states carry influence outward. This partition is the foundation of selfhood in the FEP.

Prediction Error Dynamics

$$\varepsilon_i = o_i - g_i(\mu_{i+1})$$
$$\dot{\mu}_i = \varepsilon_i - \varepsilon_{i+1} \cdot \frac{\partial g_{i+1}}{\partial \mu_i}$$

Each layer predicts the activity below. Prediction errors ε propagate upward, weighted by precision π. High precision → errors dominate (sensory-driven). Low precision → priors dominate (belief-driven).

Expected Free Energy

$$G(\pi) = \underbrace{-\mathbb{E}[\text{D}_{KL}[q(s|o,\pi)\|q(s|\pi)]]}_{\text{Epistemic Value (info gain)}} - \underbrace{\mathbb{E}[\ln p(o|C)]}_{\text{Pragmatic Value}}$$

The active inference agent selects policies π that minimize G. Epistemic value drives exploration (reducing uncertainty). Pragmatic value drives exploitation (seeking preferred outcomes). No exploration-exploitation trade-off needed — it emerges naturally.

Precision-Weighted Inference

$$\mu_{post} = \frac{\pi_0 \mu_0 + \pi_\ell \mu_\ell}{\pi_0 + \pi_\ell}$$
$$\pi_{post} = \pi_0 + \pi_\ell$$

The posterior mean is a precision-weighted average of prior and likelihood. Higher precision = more influence. This is how the brain resolves conflicting information — trusted sources get more weight.

Why Curiosity Is Free

$$G(\pi) = -\omega_e \cdot \underbrace{I(o;s|\pi)}_{\text{Info Gain}} - \omega_p \cdot \underbrace{\mathbb{E}[\ln p(o|C)]}_{\text{Pragmatic}}$$

When uncertainty is high, epistemic value dominates → agent explores. When uncertainty is low, pragmatic value dominates → agent exploits. No ad-hoc exploration bonus needed — it falls out of the math.

The Fisher Information Metric

$$g_{ij}(\theta) = \mathbb{E}\left[\frac{\partial \ln p(x|\theta)}{\partial \theta_i}\frac{\partial \ln p(x|\theta)}{\partial \theta_j}\right]$$

The Fisher information matrix defines a Riemannian metric on the space of probability distributions. Natural gradient descent follows geodesics on this manifold, converging faster than ordinary gradient descent — this is how the brain updates beliefs.
